# Tienda Virtual con Flask

Taller básico de una tienda virtual hecha con Flask y un catálogo en JSON.

## Cómo ejecutar

1. Crear y activar el entorno virtual:

   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

2. Instalar Flask:

   ```bash
   pip install -r requirements.txt
   ```

3. Iniciar la tienda:

   ```bash
   python run.py
   ```

4. Abrir http://127.0.0.1:5000 en el navegador.

El catálogo está en `app/data/productos.json`. Cada producto tiene una página de detalle.
